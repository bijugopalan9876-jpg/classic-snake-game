🐍 Snake Game

A classic Snake Game developed using **Python and Pygame-CE**.

 About
The player controls a snake, eats food, increases the score, and grows the snake. The difficulty increases as the score increases.

##  Features
- Snake movement
- Food generation
- Score tracking
- Snake growth
- Collision detection
- Increasing difficulty
- Game Over and Restart

##  Technologies
- Python
- Pygame-CE
- VS Code
- GitHub
